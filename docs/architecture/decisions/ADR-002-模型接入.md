# ADR-002：模型接入 — OpenAI 兼容云端 API 优先，本地预留

- 状态：已接受
- 日期：2026-10-21
- 关联：ADR-000；基线决策 D3、D5（ADR-003）；规范 §2（角色不绑定模型）

## 背景

平台需要模型能力完成各角色任务，但 Phase 1–2 必须**模拟先行**（实施计划 §2.1），不依赖真实模型、不产生费用；Phase 4（P4-1）才接入真实模型。最终产品面向 Windows 桌面用户，模型配置（含密钥）由用户完成。

## 决策

1. **统一适配器协议**：`adapters/models/` 定义单一 `ModelAdapter` 接口（complete/stream/结构化输出/取消/用量上报）。
2. **首选实现：OpenAI 兼容云端 API**（`config/models.yaml` 的 `cloud-openai-compatible` profile）：base_url/api_key/model 全部经环境变量或系统凭据库注入，不硬编码（符合 D3）。
3. **本地模型预留**：`local-reserved` profile 占位（OpenAI 兼容端点如 Ollama 走同一协议，实现推迟到 P4 后按需求评估）。
4. **模拟适配器（Phase 1–2）**：脚本化响应、可注入超时/错误/格式错误，用于验证状态机与失败处理（P1-6）。
5. 结构化输出一律经 JSON Schema 校验；校验失败按错误处理进入重试/阻断，不静默降级。

## 备选方案对比

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| A. OpenAI 兼容统一协议＋provider profile | 一套适配器覆盖主流云厂商与本地端点；用户配置简单 | 厂商特有功能需扩展字段 | **采用** |
| B. 每厂商独立 SDK 适配器 | 功能全 | N 倍维护成本；Phase 1 不必要 | 拒绝（接口已预留扩展） |
| C. 本地模型优先 | 隐私/离线 | 受用户硬件限制大、质量不稳，违背 D3 | 拒绝（保留 local-reserved） |
| D. 平台内置固定模型/密钥 | 用户零配置 | 成本与合规风险不可控，不可行 | 拒绝 |

## 结论

- `config/models.yaml` 中云端 profile 默认 `enabled: false`，Phase 4 由用户显式配置后启用；在此之前任何"真实模型调用"声明均视为违规。
- 不可用时**明确报错并标记未验证**，不伪造连接成功（红线 2）。
- 用量（Token/成本，可得时）随 AgentRun 记录入审计（规范 §18、D10）。
